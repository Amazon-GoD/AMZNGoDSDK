EagleExoPlayer For Android

EagleExoPlayer is using Google ExoPlayer Class.

Streaming services are also supported.(Internet Access option is checked, the streaming service )

From Android version 4.1 or later are supported.

The ExoPlayer source of the following site.
(https://github.com/google/ExoPlayer)

Editor On the Android Platform API can not be used ....

Only works with Android devices.

If you want to test run the Demo, you need to move the StreamingAssets folder to the root directory
