AMZN GoD SDK for Unity

Cross-promo: [настройка мастер JSON и смена JSON без пересборки](Runtime/Modules/Cross-Promo/README.md).

При включении и сохранении модуля AppLovin Google AdMob автоматически устанавливается вместе с обязательными адаптерами MAX. До Android-сборки укажите собственный Android App ID AdMob в AppLovin → Integration Manager → Google Bidding and Google AdMob → App ID (Android). Сборка останавливается, если App ID отсутствует или имеет неверный формат.
